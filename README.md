# Simple Interest Calculator

## Description
This project calculates simple interest
based on the principal amount, interest rate,
and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Example
Principal = 1000
Rate = 5%
Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100 = 100

Total Amount = 1000 + 100 = 1100
